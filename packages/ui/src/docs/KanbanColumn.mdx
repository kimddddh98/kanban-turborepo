# Kanban Column

## 목적

`KanbanColumn`은 칸반 보드의 컬럼 레이아웃(헤더/카운트/본문 영역)을 담당하는 컴포넌트입니다.  
카드 리스트, 빈 상태, 추가 버튼은 `children`으로 주입해 조합합니다.

---

## 구성 관계

- 컬럼 레이아웃: `KanbanColumn`
- 카드 아이템: `KanbanCard`
- 카드 추가 액션: `AddCardButton`
- 빈 상태 표시: `EmptyColumnState`
