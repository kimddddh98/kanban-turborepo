# Checkbox

## 목적

Checkbox는 사용자의 선택 여부를 on/off 형태로 표현하는 기본 선택 컴포넌트입니다.  
현재 디자인 토큰 기반으로 보더, 배경색, 체크 상태, 텍스트 색상을 일관되게 적용합니다.

---

## 사용 가이드

### Do

- 독립적인 동의/선택 항목에 Checkbox를 사용합니다.
- 라벨은 사용자가 이해하기 쉬운 문장형으로 작성합니다.
- 보조 설명이 필요하면 `description`을 함께 제공합니다.

### Don’t

- 서로 배타적인 선택에는 Checkbox 대신 Radio를 사용합니다.
- 체크 상태에 의미 없는 긴 본문 텍스트를 라벨로 넣지 않습니다.

## 접근성(Accessibility)

- 네이티브 `input[type="checkbox"]`를 사용합니다.
- `label`과 `htmlFor`를 연결해 라벨 클릭으로도 체크를 변경할 수 있습니다.
- 키보드 포커스 시 보더 색상만 변하고 크기는 유지됩니다.

---

## 토큰/테마(Design Tokens)

현재 Checkbox는 아래 토큰 및 컬러 클래스를 사용합니다.

- 기본 배경: `bg-white`
- 기본 보더: `border-gray-400`
- 체크 상태 배경: `checked:bg-accent-default`
- 체크 상태 보더: `checked:border-accent-default`
- 포커스 보더: `focus:border-accent-default`
- 라벨 텍스트: `text-fg-default`
- 설명 텍스트: `text-fg-subtle`

즉 Checkbox의 시각 상태는 하드코딩된 컴포넌트 변형보다 토큰 값 변경에 더 가깝게 반응합니다.

## 메모

- 현재 구현은 단일 체크박스 기준입니다.
- 여러 항목을 묶어 관리할 때는 상위에서 배열 상태를 관리하는 CheckboxGroup 계층이 필요합니다.
